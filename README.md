# Amareke Marketing Site (Next.js + Tailwind)

## Run locally
1. Install Node.js 18+
2. `npm install`
3. `npm run dev`
4. Visit `http://localhost:3000`

## Pages
- `/` Home
- `/product` Product
- `/pricing` Pricing
- `/resources` Resources
- `/company` Company
- `/demo` Live demo placeholder page

## Notes
- This is a static marketing site with placeholder screenshots in `public/screens`.
- Animations are lightweight (scroll reveal + subtle shine effect).
- If you want the interactive demo back (hooks/captions generator simulator), we can add it as `/demo` with a Bedrock-ready API route.
